# 行事予定管理アプリ

学校の年間の行事予定を入力・管理し、月間予定表・年間予定表(教員用・家庭用)を作るアプリです。
給食の日数、授業時数の集計、学級ごとの実績の管理もできます。以前 Excel のマクロで行っていた作業を置き換えるものです。

## 使い方

1. 校務共有サーバーにある `index.html` を、**Chrome または Edge** で開きます。
2. データのファイルを開きます。
   - **見るだけの先生**:何も選ぶ必要はありません。`index.html` を開くと、同じフォルダの `行事予定_2026年度.js`(名前の年度が一番新しいもの)が自動で開きます。
   - **編集する先生**:最初に1回だけ(パソコンごと)、「🔒 編集する」を押したときに出る画面で、**アプリ(`index.html`)のあるフォルダ**を選びます。次からは許可のボタンを1回押すだけです。
   - 開いたまま置いておいても、ほかの先生が保存した新しい内容は自動で読み直されます(画面に戻ったときと1分おき)。「編集する」を押したときも、最新の内容から編集が始まります。
3. 入力や変更をするときは、「🔒 編集する」を押して名前を入れ、編集モードにします(パスワードはありません)。
   - 同時に2人が編集しないよう、編集中はほかの先生の画面に表示が出ます。終わったら「編集を終える」を押してください。
4. 画面上のタブで作業を切り替えます。

| タブ | できること |
|---|---|
| 予定入力 | 日ごとの行事・会議・給食・①〜⑥の授業などを入力する。学校行事等はマスをクリックすると右側に入力欄が出て、行事ごとに「年間」「月間」「教員のみ」のチェックで載せる先を決める。「保護者来校」にチェックした行事は、家庭用の予定表で太字・大きめになる(色で見分けられる) |
| 月間予定表 / 年間予定表 | 教員用・家庭用の予定表を確認し、Excel に出力する |
| 給食 | 給食の実施日数・喫食数を確認する |
| 時数・集計 | 授業時数・授業日数・授業週数を集計する。道徳・学活・総合のある日と、その日の行事を一覧にする |
| 実績 | 学級ごとの時間割を入れて、教科ごとの時数を集計する |
| 設定 | 学校名・祝日・データのフォルダ・新しい年度のファイル・バックアップの件数など |

詳しい使い方は、アプリ内の「使い方 / マニュアル」にあります。

## データの保存場所

- データは、**データのフォルダ**(校務共有サーバー上)に、年度ごとに `行事予定_2026年度.js` のような名前で置きます。年度は4月始まりです。編集中の変更は、このファイルに自動で上書き保存されます。画面の上に、今開いているファイル名が出ます。
- アプリはデータのフォルダを覚えていて、開くと名前の年度が一番新しいファイルを開きます(ファイルの更新日時ではなく、名前で決めます)。
- **新しい年度**:今の年度のファイルがまだないときは、画面上部に「○年度のファイルを作る」が出ます(設定タブにもあります。次の年度の予定を早めに組むときはこちら)。設定・入力候補・前の年度の予定を引き継ぎ、編集の記録・行事の時数の手入力・版の表示は引き継ぎません。自動では作りません。
- 中身は JSON という形式の文字データで、メモ帳などでも開けます(直接書き換えないでください)。
- **以前のファイルからの移し替え**:データのフォルダに `行事予定_○年度.js` がないときは、フォルダの中の一番新しい `.json`(以前の `.dat` も)が見るだけで開き、「`行事予定_2026年度.js` の名前で保存し直す」ボタンが出ます。押すと、次からはそのファイルが開きます。**エクスプローラーでファイルをコピーして日付の名前にする運用は、もうやめてかまいません。**
- 実際の行事予定は校内でだけ扱います。**インターネットやクラウド(Googleドライブ等)には置かないでください。**

## バックアップと復元

- **自動バックアップ**:編集を始めるとき、その日のバックアップがまだなければ、データのフォルダの中の `バックアップ` フォルダに `行事予定_2026年度_バックアップ_2026-11-21_0830.js` を1つ取ります(編集を始める前の内容。何人が編集しても1日1つ)。元に戻す前・新しい年度のファイルを作る前にも取ります。
- **バックアップの整理**:アプリでは消しません。件数は設定タブに出ます。多くなったら、エクスプローラーで `バックアップ` フォルダの古いものを消してください(例:1年より前のもの)。
- **手で控えを取る**:設定タブの「データを書き出す(バックアップ)」で、今の内容をこのパソコンの「ダウンロード」に保存できます。
- **復元**:「データを読み込む(復元)」で、`バックアップ` フォルダのファイルなどを選びます。**見るだけ**で開くので、内容を確かめてから、画面上部の「この内容に戻す」を押します(先に、いつものファイルのバックアップを取ります)。やめるときは「いつものファイルに戻る」を押します。次にアプリを開いたときも、いつものファイルが開きます。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 入力できない | 編集モードになっているか確認してください(「🔒 編集する」を押して名前を入れます)。 |
| 「別の場所でこのファイルが編集中です」と出る | ほかの先生が編集中です。終わるのを待ってください。 |
| ファイルが開かない・「データのフォルダを開けませんでした」と出る | 共有サーバーにつながっているか確かめて、設定タブの「データのフォルダを選ぶ」で選び直してください。 |
| 「見るだけで開いています」と出て編集できない | 「データを読み込む(復元)」で開いたファイルは見るだけです。「いつものファイルに戻る」を押してください。その内容に戻したいときは「この内容に戻す」を押します。 |
| 「今の年度のファイルがまだありません」と出る | 新しい年度のファイルを作る係の先生が「○年度のファイルを作る」を押してください。それまでは前の年度のファイルが開きます。 |
| 「新しい年度のファイルがあります」と出る | ほかの先生が新しい年度のファイルを作りました。ボタンを押して開いてください(次からは自動で開きます)。 |
| 「ほかの場所で保存されています」と出る | ほかの先生(または別のタブ)が先に保存しています。「キャンセル」を押し、入力した内容を控えてから、ページを開き直して入力し直してください。 |
| データがおかしくなった | 「データを読み込む(復元)」で `バックアップ` フォルダのファイルを選んで確かめ、よければ「この内容に戻す」を押してください。 |
| Chrome・Edge 以外で開いている | 自動保存が使えません。Chrome か Edge で開き直してください。 |

## 後任の先生・開発者へ

- 仕組み・データの形・注意点・次にやることは [HANDOFF.md](HANDOFF.md)、細かな変更の経緯は [TODO.md](TODO.md)、変更の記録は [CHANGELOG.md](CHANGELOG.md) にあります。
- 学校名・年度・学期の区切り・祝日・必要時数・入力候補・色などは、アプリの「設定」タブで変えられます。
- 外部のライブラリは使っていません(Excel の出力もこのファイルの中で作っています)。
- `サンプルデータ_1年分.json` は架空のサンプルデータです。

## データのファイル(.js)について

- データのファイル(`行事予定_○年度.js`、バックアップも `.js`)は**ダブルクリックせず、アプリから開いてください**(Windows がプログラムとして動かそうとしてエラーの画面が出ます。中身は壊れません)。
- **見るだけの先生は、フォルダを選ぶ必要はありません。** アプリ(index.html)を開くだけで、同じフォルダの一番新しい年度のファイルが開きます。フォルダを選ぶのは、編集する先生が最初に「編集する」を押したときの1回だけです(アプリと同じフォルダを選びます)。
- 以前の `.json`・`.dat` も「データを読み込む(復元)」で読めます。

## まだ確かめていないこと

- `<script src>` で読む見るだけの開き方は、実物の共有サーバー(ファイルとして開いたとき)では**未確認**です。

- データのフォルダ・バックアップ・新しい年度のファイル・「この内容に戻す」は、作りもののフォルダで動きを確かめました。**実物の校務共有サーバーのフォルダでは、まだ確かめていません**(フォルダを選ぶ画面、許可のボタン、`バックアップ` フォルダが作られるか、ほかのパソコンでの見え方)。

## 編集中の表示と編集の記録

- 「🔒 編集する」を押すと、名前を入れます(パスワードはありません)(名前が空では始められません。名前はこのパソコンのブラウザが覚えます)。
- ほかの先生が編集中のときは、上に「○○先生が編集中(15:20〜)」と出ます(15分以上保存のない印は消えます)。
- 上の「編集の記録」ボタンで、だれが・いつ編集したか(始めた時刻〜最後に保存した時刻)を新しい順に見られます。何を変えたかは記録しません。200件まで残ります。見本データには架空の記録が入っています(見本で試している間は記録しません)。

## Googleカレンダーに取り込む

1. 「年間予定表」タブで「📅 Googleカレンダー用に書き出す」を押します。
2. 対象(教員用・家庭用)と期間(月)を選び、「月間」だけの行事も入れるかを決めて「書き出す」を押します。カレンダー用のファイル(.ics)が保存されます。
3. パソコンで Googleカレンダーを開き、⚙(設定)→「設定」→ 左の「インポート / エクスポート」で、そのファイルを選び、入れる先のカレンダーを選んで「インポート」を押します。

- 行事はすべて終日の予定です。「年間」の行事は1つずつ別の予定に、それ以外の行事はその日ごとに1つにまとめます。祝日名は入れません(Googleカレンダーの祝日と重なるため)。
- 同じ期間を書き出し直して取り込むと、同じ行事は上書きされ、重なりません。行事名を直した・消した行事は古いものが残るので、取り込み用のカレンダーを1つ作っておき、作り直してから取り込むときれいになります。
- 書き出したファイルには行事予定が入っています。インターネット上の共有フォルダなどには置かないでください。
